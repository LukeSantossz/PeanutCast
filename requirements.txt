# Este arquivo é o único lugar do projeto onde versão de biblioteca aparece.
# Os documentos citam o nome da biblioteca, nunca o número: se o número
# estivesse em dois lugares, um dia os dois discordariam, e quem descobre é
# quem tenta rodar o projeto na véspera da entrega.
#
# Todas as versões estão travadas com "==" de propósito. O cronograma pede que
# os quatro rodem o mesmo código com as mesmas bibliotecas, e num projeto de
# dois meses uma atualização silenciosa de biblioteca é bug que ninguém
# consegue reproduzir.
#
# Para subir uma versão: troque aqui, rode o app, e avise o grupo. Todo mundo
# roda o pip install de novo. Não suba versão sozinho na sua máquina.
